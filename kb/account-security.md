title: Account security and sign-in
updated: 2026-04-18
---
Two-factor authentication (2FA) can be turned on in Settings > Security using an authenticator app. SMS-based 2FA is not offered.

Single sign-on (SSO) with SAML is available on the Scale plan.

Password reset links expire after 1 hour. If the link has expired, request a new one from the sign-in page.

If you think someone else has accessed your account, change your password immediately and contact a human agent so the security team can review account activity. The assistant cannot review account activity.
